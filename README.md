## 先把老问题答完：合并前 X Premium+ 的 Grok 额度是什么水平

X Premium+ 最后一版定价是 **40 美元/月**（美国区）。它的 Grok 额度，官方从来没公布过具体数字，多少条消息、多少次生成，一律不写。能确认的是相对关系：**它的 Grok 侧限制和 30 美元的 SuperGrok 基本持平**，同样能用当时的最新模型、DeepSearch、Big Brain 扩展思考、语音模式和 Grok Imagine 的图像视频生成，共享同一个用量池。

多出来的 10 美元，买的是 X 平台权益：无广告浏览、更高的创作者分成比例、更长的推文上限、回复排序加权。换句话说，X Premium+ 从来就不是“Grok 额度更大”的档位，它贵在 X 功能。如果你当年冲着“更高级所以额度更多”去订，那笔钱其实没花在额度上。

价格轨迹也值得一提：2024 年底调价后是 22 美元/月，到 2026 年年中已经涨到 40 美元，一年半接近翻倍，这也是它争议最大的地方。

### 额度按“每周用量池”算，不按小时

2026 年 6 月起，所有付费 Grok 套餐改成**单一每周用量池**：聊天、图像视频生成（Imagine）、语音（Voice）、应用搭建（Build）共用一个池子，每周重置，不再按“每 2 小时 N 次”的老方式限流。用量在设置的 Usage 页面查看。

### 用完了会怎样

不会被直接锁死。每周池耗尽后，账号回落到免费层的 Chat 和 Voice 限额，基础对话还能继续。真不够用，可以买 Extra Usage Credits 补充包：5 美元起步，仅限网页端购买，一年内有效，按标准费率计价。官方自己的建议很直白，经常买补充包的人，不如直接升一档。

## 几个高频问题

**我还在订老的 X Premium+，会怎么样？**
公告和目前的报道都没提存量订阅的处理细节。稳妥的做法是去订阅管理页确认当前档位和官方提示。按权益重合度看，原 X Premium+ 的核心体验现在对应 30 美元的 Premium。

**8 美元的 Plus 和原来的 X Premium 是一回事吗？**
价格一样，内容变多了。原 X Premium 主要是认证标、减广告、创作者变现加基础 Grok 访问；新 Plus 在此之上加了共享用量池和 Cursor。

**SuperGrok 的单独套餐还能买吗？**
不能了，原来的多档体系被整体替换。原 SuperGrok 的位置由 Premium 接替（Grok Bot 现在从这一档起），10 美元的 SuperGrok Lite 这类过渡档也一并并掉了。

**免费版还剩多少 Grok 额度？**
有限的 Grok Chat，新免费档据报道还包含基础图像生成。具体数字官方历来不公布。付费用户把每周池用空后，也是回落到这层限额，不至于完全停摆。

**订阅额度和 Grok API 是一回事吗？**
不是。API 按 token 计费，当前的旗舰 Grok 4.7 是每百万输入 token 2 美元、输出 6 美元，500k 上下文；旧一些的 Grok 4.3 还能以 1.25 / 2.50 美元的价格用。不过 8 美元的 Plus 现在自带 Grok API 访问，调用也从共享池里扣，小体量的开发需求基本不用单独走 API 计费。

额度规则刚换，接下来几周大概率还有细节陆续补齐。与其记具体数字，不如定期看一眼用量页面的池子消耗速度——你自己的数据最诚实。
